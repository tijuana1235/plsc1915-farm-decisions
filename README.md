# PLSC1915 Farm Decisions

Two browser-based classroom tools for comparing capital investments in Stardew Valley.

- [Before Ten: early capital choices](https://tijuana1235.github.io/plsc1915-farm-decisions/early-game.html) — compare tool upgrades, sprinklers, processing equipment, mixed plans, and saving; inspect cumulative net profit and investment recovery.
- [The Next Keg: harvest and wine](https://tijuana1235.github.io/plsc1915-farm-decisions/) — compare crop portfolios, irrigation, processing capacity, and planning periods on Ginger Island.

## Use

Open either link in a browser. No student account or installation is required. The apps calculate in the browser. Written responses stay in the current page until downloaded; reloading clears them. Downloading does not submit work to an instructor.

To use offline, download the repository and keep the six app files together. Open `early-game.html` or `index.html`. Source links require internet access.

## Model boundaries

These are conditional teaching models. Crop rules and prices have source links in the apps; action timings, routes, and the 10 p.m. bedtime are classroom assumptions. Food costs, resource gathering, other uses of saved time, and equipment value remaining at the cutoff are omitted. Results have not been calibrated against gameplay.

The early app distinguishes cumulative modeled net profit from the additional return compared with keeping equipment. Equipment costs are counted once. Normal recipe unlocks apply unless the explicit classroom access override is selected.

## Hosting

GitHub Pages serves the `main` branch at the repository root. `.nojekyll` publishes the static files without Jekyll processing. No build step or backend is required.

Game names and references identify the classroom subject. This is an independent teaching tool, not an official Stardew Valley product.
